# Дизайн интерфейса

Скриншоты «до» и «после» — в `docs/screens/` (десктоп 1440×900 и 375 px).

## Критика текущего интерфейса

**Первое впечатление.** Глаз сначала цепляют фиолетовые активные кнопки тулбара (их шесть
одновременно), а не иллюстрация. Сиреневый цвет вшит в CSS и не меняется со схемой:
при персиковой схеме интерфейс остаётся фиолетовым.

| Находка | Важность | Решение |
|---|---|---|
| Тулбар из 18 одинаковых кнопок в 2 ряда, группы не различимы | высокая | сегментированные контролы с подписью-группой, схемы — образцами цвета, «Скачать SVG» справа |
| Библиотека — текстовые кнопки, объект не видно до добавления | высокая | карточки с миниатюрой настоящего SVG в текущей схеме |
| На 375 px холст оказывается в самом низу, под всей панелью | высокая | на узком экране сначала тулбар и холст, потом панель |
| Нет состояния загрузки сценария А, кроме текста; ошибка выглядит как обычный статус | средняя | индикатор в кнопке + skeleton на холсте, ошибка — отдельным стилем с иконкой |
| Кнопки порядка слоёв — символы ⤒↑↓⤓ без подписи для скринридера | средняя | иконки lucide + `aria-label` |
| Слои — `<li onClick>`, недоступны с клавиатуры | средняя | кнопки внутри списка |
| Нет `:focus-visible`, `aria-pressed` у переключателей | средняя | общее кольцо фокуса, `aria-pressed` |
| Синяя пунктирная рамка выделения не связана с палитрой | низкая | рамка цветом акцента схемы |
| Пустой холст: подсказка на полупрозрачной плашке | низкая | спокойный текст по центру холста: заголовок + одна строка |

Хорошо: холст крупный, все функции в одном экране, рабочий drag-and-drop.

## План

**Сетка.** Шаг 4 px, отступы 8/12/16/24. Панель 320 px слева, справа сцена:
тулбар (одна строка на десктопе, перенос по группам на узких экранах) и холст по центру.
На ширине < 800 px — одна колонка: тулбар → холст → панель.

**Иерархия панели.** Создать (А — по смыслу, Б — по названиям) → Библиотека →
Объект (только при выделении) → Слои. Заголовки секций 12 px, полужирные, с разделителем.

**Типографика.** Golos Text (кириллический гротеск, @fontsource, локально),
начертания 400/500/600. Размеры: 13 (основной UI), 12 (подписи, метки групп), 15 (логотип).

**Цвет.** Нейтральная тёплая серая основа (`#f4f4f2` фон, `#fff` панель, `#e4e3df` линии,
текст `#181817` / `#5c5b57`). Акцент — из активной схемы через CSS-переменные:
`--accent-soft` = `bg1` (фон активных элементов), `--accent-strong` = смесь `bg3` и `ink`
60/40 (рамки активных элементов, кольцо фокуса, рамка выделения). Текст на акцентах
всегда `ink`; контраст ≥ 4.5:1 проверяется тестом для всех схем. Основная кнопка —
`ink` с белым текстом. Скругления 6–8 px, тени только у холста (1 px линия вместо тени).

**Состояния.** hover — фон на тон темнее; active (нажатие) — сдвиг 1 px; on —
`--accent-soft` + рамка `--accent-strong`; focus-visible — кольцо 2 px `--accent-strong`
с отступом 2 px; disabled — 40 % непрозрачности и `cursor: not-allowed`.
Пустой холст, загрузка А (спиннер в кнопке, skeleton на холсте, `aria-busy`), ошибка
(красный текст с иконкой, `role="alert"`).

**Анимации (motion).** Анимируется только внутренняя обёртка объекта, внешний
`<g data-uid transform>` не трогаем.
- Появление: opacity 0→1, scale 0.92→1, y 8→0 px, 220 мс, ease-out; при сборке каскад 40 мс.
- Удаление: 160 мс, fade + scale до 0.96 (AnimatePresence), затем узел уходит из DOM.
- Пресет/формат: FLIP внутренней обёртки — старая матрица → новая за 300 мс.
- Перетаскивание, поворот, S/L, масштаб — мгновенно.
- `prefers-reduced-motion: reduce` — все анимации и CSS-переходы выключены.
