# План

**Стек:** Vite + React + TypeScript (фронтенд), серверная функция `api/compose.ts`
(Vercel; локально — та же функция как middleware Vite), Vitest, Playwright.

1. Данные из Figma: 10 объектов × 2 вида (главный/фоновый) × 2 размера (S/L) → `assets/objects/*.svg`
   (как есть, только нормализация id/цветов), `src/data/manifest.json`, `src/data/schemes.json`.
2. Перекраска: объекты нарисованы в сиреневой схеме → цвет-источник ↦ роль ↦ цвет целевой схемы.
3. Холст: SVG, объекты — `<g transform>` с исходной разметкой внутри. Добавить, двигать,
   поворот, дублировать, удалить, слои, вид главный/фоновый, формат, S/L, схема.
4. Пресеты раскладки (чистые функции): «Собранно», «Со смещением», «Под заголовок»;
   у всех один общий коэффициент масштаба.
5. Сценарий Б: разбор названий (синонимы, словоформы, опечатки — Левенштейн).
6. Сценарий А: `/api/compose` → OpenRouter (`:free`, список запасных моделей, таймаут, кэш),
   строгий JSON, валидация id по каталогу; без ключа/при ошибке — поиск по тегам.
7. Экспорт: та же функция рендера, что и холст → SVG без `<image>`.
8. Тесты (Vitest) + e2e (Playwright) обоих сценариев, деплой, README, /examples.
